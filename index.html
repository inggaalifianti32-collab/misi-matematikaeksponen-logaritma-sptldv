Definisi & Sifat-Sifat Utama Logaritma

Bentuk Eksponen

ac = b

⇔
Bentuk Logaritma

alog b = c

Syarat: Basis a > 0, a ≠ 1 dan Numerus b > 0. Contoh: 23 = 8 ⇔ 2log 8 = 3.

Sifat Identitas & Pangkat

alog a = 1  |  alog 1 = 0

alog (bn) = n · alog b

Sifat Perkalian & Rantai

alog(b × c) = alog b + alog c

alog b × blog c = alog c

Anatomi Notasi Logaritma

Menentukan Grafik & DHP SPtLDV

  • 1 Persamaan Garis dari Titik Potong Sumbu: Jika garis memotong sumbu Y di (0, a) dan sumbu X di (b, 0), maka persamaan garisnya adalah ax + by = a · b.
  • 2 Jenis Garis Pembatas: Gunakan garis penuh (solid) untuk tanda ≤ atau ≥, dan gunakan garis putus-putus (dashed) untuk tanda < atau >.
  • 3 Uji Titik (0,0): Substitusikan (0,0) ke pertidaksamaan. Jika pernyataan bernilai Benar, arsir daerah yang memuat (0,0). Syarat x ≥ 0, y ≥ 0 berarti DHP berada di Kuadran I.

Contoh DHP: 6x + 5y ≤ 30, x ≥ 0, y ≥ 0
